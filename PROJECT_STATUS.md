# OmniSEO Tools — Architecture & System Status

## 1. Core Architecture
- **Framework:** Next.js (App Router), Tailwind CSS, TypeScript.
- **Hosting:** Vercel (Canonical Apex: `https://omniseotools.com`).
- **Target URL Structure:**
  - Standard Tools: `/tools/[slug]`
  - Programmatic Permutations: `/tools/[slug]/[platformSlug]`
  - Platform Hubs: `/platforms/[platformSlug]`
  - Directory Index: `/platforms`
  - Technical Engineering Blog: `/blog` and `/blog/[slug]`
- **Zero-Maintenance Static MDX Blog Infrastructure & Tool Feedback Loop:** 100% SSG developer blog engine powered by `src/lib/blog.ts`, `gray-matter`, `reading-time`, and `@tailwindcss/typography`. Prerenders high-intent technical articles (`/blog/[slug]`) at build time with type-safe frontmatter, dynamic reading time, interactive embedded `<ToolCallout />` widgets, and zero database dependencies. Bidirectional conversion feedback loop connects technical blog posts with live tools (`Open Graph Generator`, `Twitter Card Previewer`, `Campaign UTM Builder`).
- **Dynamic Social Share Images (OG Cards):** Edge runtime `ImageResponse` (`@vercel/og`) generators dynamically render high-contrast 1200x630 branded social cards with dynamic titles, category badges, platform pills, and value props across `/tools/[slug]/opengraph-image`, `/tools/[slug]/[platformSlug]/opengraph-image`, and `/blog/[slug]/opengraph-image`.
- **Feature Comparison Matrix:** Programmatic `ComparisonMatrix.tsx` component injected across standalone and platform permutation tool routes, comparing traditional SaaS suite friction (server queues, database logging, email paywalls) with OmniSEO Tools' zero-latency, client-side, paywall-free architecture.
- **Structured Data (JSON-LD):** Programmatic injection of Schema.org `WebApplication`, `TechArticle`, `BreadcrumbList`, and `FAQPage` via `src/lib/schema-generator.ts` and `src/components/seo/JsonLd.tsx` across standalone tools, platform permutations, hub routes, blog articles, and dedicated tool routes.
- **On-Page SEO Boost & High-Intent Editorial Content:** In-depth technical documentation blocks (Open Graph aspect ratios, crawler cache invalidation, GA4 campaign parameter roles, Default Channel Grouping matrices, Twitter card format requirements, cache-busting mechanics, and FAQ accordions) back-linked by valid Schema.org `TechArticle` and `FAQPage` structured data to target high-intent search queries.
- **Platform Resilience, Component Error Boundaries & Micro-Feedback System (Sprint 21):** Component-level (`src/components/common/ToolErrorBoundary.tsx`) and route-level (`src/app/(site)/tools/[slug]/error.tsx`, `src/app/error.tsx`) error boundaries provide isolated runtime failure protection without crashing page layouts. Integrated floating `<MicroFeedbackDrawer />` with client diagnostics auto-capture (URL, tool slug, screen resolution, user agent, error stack trace) and multi-channel backend dispatch via `/api/feedback` (Resend email API, Webhook, dev logging). Global `<SystemStatusPill />` embedded in the footer provides real-time operational status and latency checks for core services.
- **Sitemap:** Dynamic (`src/app/sitemap.ts`) generating 260+ canonical apex URLs with proper priorities (22 core tools + /tools hub directory + 160 programmatic permutations + 9 platform hubs + /blog directory + 2 blog posts + legal pages).

## 2. Shared Libraries & Engine
- **Open-Source Engine:** Uses `@omniseo-core` (or `src/lib/core`) for underlying calculation logic (keyword density, SERP length calculators, meta tag validators, diacritic transliteration).
- **Interactive Embedded MDX Components & Prose Typography:**
  - `src/components/blog/MDXComponents.tsx`: Unified MDX layout and semantic element mapping ensuring fluid prose typography, responsive tables with horizontal scroll safety, and styled blockquotes.
  - `src/components/blog/SafeZoneDiagram.tsx`: Visual, responsive canvas diagram depicting Open Graph 1200x630 pixel dimensions, 60px margins, and platform compatibility tags.
  - `src/components/blog/ToolCallout.tsx`: High-converting sandbox launcher connecting editorial debugging articles with live browser utilities.
  - `src/components/blog/CodeBlock.tsx`: Syntax-styled pre/code wrapper with filename headers and 1-click clipboard copy state.
  - `src/components/blog/FaqAccordion.tsx`: Accessible interactive Q&A accordion with automatic Schema.org `FAQPage` JSON-LD injection.
- **Client-Side Social Image Resizer & Standard 1200x630 Cropper:** `src/lib/image-resizer.ts` provides zero-latency image cropping and scaling using an off-screen HTML5 canvas to format social images to the standard 1.91:1 Open Graph ratio (1200x630px). Integrated inline action "⚡ Fix to 1200x630" across `SocialPreviewer.tsx` and `MetaTagGenerator.tsx` with center-crop calculations, Blob downloads, and a 2-tier fallback to `/api/proxy-image` to bypass remote host canvas CORS tainting seamlessly.
- **Local Image Upload Dropzone & WebP Optimizer:** `processLocalImageFile` in `src/lib/image-resizer.ts` enables 100% in-browser image uploads with drag-and-drop support across `SocialPreviewer.tsx` and `MetaTagGenerator.tsx`. Auto-crops to 1200x630, encodes to high-efficiency WebP, computes byte-size reduction metrics, provides instant live previews without server uploads, and enables 1-click WebP downloads.
- **Server-Side CORS Bypass Image Proxy Engine:** `src/app/api/proxy-image/route.ts` provides SSRF-protected server-side image proxying with an 8-second timeout budget (`AbortSignal.timeout(8000)`), content-type validation (`image/*`), and open `Access-Control-Allow-Origin: *` headers, enabling 100% reliable canvas pixel reads for external social images.
- **Client-Side URL State Sharing Engine:** `src/lib/url-state.ts` provides zero-latency, 100% client-side permalink sharing for metadata generator and preview tools (`SocialPreviewer.tsx`, `MetaTagGenerator.tsx`). Compresses form inputs into URL hash fragments (`#s=...`) using UTF-8 safe base64 JSON serialization with instant mount hydration, non-reloading history replacement, and zero network/database dependencies.
- **Live URL Metadata Inspection Engine:** `src/app/api/scrape-meta/route.ts` provides SSRF-protected server-side HTML scraping with strict 5-second timeout budgets (`AbortSignal.timeout(5000)`), parsing `<title>`, Open Graph tags (`og:title`, `og:description`, `og:image`, `og:site_name`, `og:url`), Twitter cards, and canonical links to power 1-click live site metadata auto-fill.
- **Client-Side Social Mockup PNG Exporter:** `html-to-image` integration in `SocialPreviewer.tsx` with dynamic SSR-safe imports and `@2x` retina scaling (`pixelRatio: 2`) allows 1-click client-side PNG downloads for Twitter/X, LinkedIn, Facebook, and Discord preview cards.
- **Multi-Framework Code Exporter:** `src/lib/formatters/metaFormatters.ts` converts meta tag configurations into clean HTML5, idiomatic Next.js App Router `Metadata` TypeScript exports, Astro snippets (`{JSON.stringify()}`), SvelteKit `<svelte:head>` components, and Shopify Liquid templates with seamless syntax switching, language-specific attribution comments, and responsive UI tab selectors.
- **Dynamic Tool Generator Engine:** `DynamicToolGenerator.tsx` renders real-time interactive form controls, preset switchers, and platform snippet integrations for all programmatic tool utilities.
- **Dynamic Vector SVG Badge API (Backlink Engine):** `src/app/api/badge/route.ts` provides an ultra-fast Edge endpoint generating Shields.io-style vector SVG badges with custom labels (`label`), statuses (`status`), score color-coding (`#10b981` >=90, `#f59e0b` 70–89, `#f43f5e` <70), themes (`dark`, `flat`, `emerald`), dynamic width calculations, 24h caching (`Cache-Control: public, max-age=86400`), and open CORS headers.
- **Embeddable SEO Audit Badge Drawer:** `src/components/tools/EmbedBadgeModal.tsx` provides 1-click Markdown (for GitHub READMEs) and HTML (for footers/docs) copyable badge snippets linking to live URL permalinks across `SocialPreviewer.tsx`, `MetaTagGenerator.tsx`, and `SERPPreviewer.tsx` to drive high-authority developer backlinks.
- **Client-Side Favicon & App Icon Generator Engine (Sprint 22):** `src/lib/favicon-generator.ts` and `src/components/tools/developer/FaviconGeneratorTool.tsx` convert single image uploads (PNG, JPG, SVG, WebP) into complete multi-size favicon suites (16x16, 32x32, `favicon.ico`, `apple-touch-icon.png` 180x180, `android-chrome-192x192.png`, `android-chrome-512x512.png`) and `site.webmanifest` JSON via offscreen HTML5 Canvas resizing. Includes 1-click `.zip` bundle packaging via `JSZip` and multi-framework code generation for HTML5 `<head>`, Next.js 14/15 App Router folder conventions & `Metadata.icons` TypeScript exports, Web App Manifests, and Astro/SvelteKit.
- **Zero-Reflow SERP Typography & Dynamic Overlay Architecture (Sprint 23):** `src/lib/serp-utils.ts` implements precomputed character metric lookup tables and bounded in-memory Map memoization caches (`TITLE_PX_CACHE`, `DESC_PX_CACHE`, `TRUNCATION_CACHE`, max 1,000 entries) to calculate pixel widths and truncate text in 0ms without synchronous DOM layout reads (`offsetWidth`, `clientWidth`, `getComputedStyle`), eliminating forced reflows during client hydration and typing. Non-critical client-heavy overlay components (`src/components/feedback/DynamicFeedbackDrawer.tsx`) are dynamically loaded via `next/dynamic` with `ssr: false`, deferring diagnostic listeners and form controllers outside the critical SSR path to maintain Total Blocking Time (TBT) below 200ms across all 260 production routes.
- **Analytics & Tracking (Sprint 23.1):** High-performance Google Analytics 4 (GA4) integration using `next/script` with `strategy="lazyOnload"` and production environment guards (`process.env.NODE_ENV === 'production'`). Offloads 171 KB `gtag.js` evaluation to browser idle time to eliminate main-thread contention, preventing mobile Total Blocking Time (TBT) spikes and ensuring zero layout shift.
- **Arabic & UTF-8 URL Decoder & Parameter Extractor (Sprint 24):** `src/components/tools/ArabicUrlDecoder.tsx` and `src/config/tools/marketing/arabic-url-decoder.ts` provide a zero-latency client-side engine to decode percent-encoded URLs, Google Ads search terms, and GA4 query strings into human-readable Arabic and UTF-8 text. Features Single & Batch line-by-line processing, auto/manual RTL direction detection (`/[\u0600-\u06FF]/`), recursive multi-hop decode resilience, URL path hierarchy breadcrumbs, query parameter classification tables, and 1-click CSV exports with Microsoft Excel UTF-8 BOM (`\uFEFF`) compatibility.

## 3. Active Registries & Taxonomy
- `src/config/tools-registry.ts`: Single source of truth for 23 active SEO/Web utilities (Campaign UTM Builder, Arabic & UTF-8 URL Decoder, Social Meta & OpenGraph Card Simulator, Twitter Card Previewer, Open Graph Generator, Keyword Density Checker, SERP Previewer, Schema Markup Generator, Canonical Tag Generator, Meta Viewport Generator, Hreflang Tag Generator, Meta Robots Builder, Security Headers Generator, Social Share Link Generator, Breadcrumb Schema Generator, FAQ Schema Generator, Favicon Meta Generator, etc.). Defines slug, categories, sample presets, and metadata.
- `src/config/platforms-registry.ts`: 8 platform definitions (Shopify, WordPress, Next.js, Webflow, Squarespace, Wix, Ghost CMS, HTML/Tailwind) with Liquid/JS/HTML presets, code snippets, FAQs, and monetization slots.
- `src/types/platform.ts`: Strict TypeScript interfaces for platforms and affiliate slots.

## 4. Monetization Infrastructure
- **Display Ad Slots:** Responsive zero-CLS placeholder containers for top leaderboard ads (`728x90` / `320x50`).
- **Affiliate Engine:** Structured `affiliateSlot` components on programmatic pages with `isPlaceholder: true` and strict `rel="nofollow sponsored noopener noreferrer"` attributes.

## 5. Immutable Engineering Rules
- Always preserve `generateStaticParams()` and dynamic `generateMetadata()` on dynamic routes.
- Preserve Edge-rendered `opengraph-image.tsx` generators without hardcoding conflicting `openGraph.images` in route metadata.
- Never hardcode affiliate destination links directly in UI components; always source through `platforms-registry.ts`.
- Maintain the bidirectional linking cluster: `Home` -> `Platforms` -> `[Platform Hub]` <-> `[Tool Permutation]` <-> `[Blog Articles]`.
- All text processing tools must support bulk inputs and preserve diacritic transliteration handling.
