# OmniSEO — Free Browser-Native Web & Social Utilities

> Live Application: [omniseotools.com](https://omniseotools.com)

OmniSEO is a lightweight, zero-latency suite of web utilities designed for content creators, webmasters, and developers. All processing runs 100% client-side in the browser.

### Featured Live Tools
- [Twitter / X Card Previewer](https://omniseotools.com/tools/twitter-card-preview): Live visual mockup for 1.91:1 summary cards.
- [LinkedIn Link Inspector](https://omniseotools.com/tools/linkedin-link-preview): Test post rendering and OpenGraph title truncation.
- [Google SERP & Title Pixel Ruler](https://omniseotools.com/tools/meta-title-pixel-checker): Accurate desktop (~600px) and mobile SERP previewer.
- [Flesch-Kincaid Readability Calculator](https://omniseotools.com/tools/flesch-kincaid-calculator): In-browser readability grade scorer.

---

## Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
